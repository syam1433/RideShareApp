# RideShare - Complete Project Description

## 📋 **Project Overview**

RideShare is a comprehensive full-stack ride-sharing application built with modern web technologies. It connects passengers with drivers for shared rides, featuring real-time communication, GPS tracking, secure payments, and a user-friendly interface. The platform includes both passenger and driver dashboards, ride booking, tracking, and a complete safety and rating system.

## 🏗️ **Project Architecture**

### **Technology Stack**

#### **Frontend (React Application)**
- **Framework**: React 18 with Vite build tool
- **Styling**: Tailwind CSS for responsive design
- **Routing**: React Router for navigation
- **State Management**: React Context API for authentication
- **Real-time Communication**: Socket.io client
- **Maps Integration**: Google Maps API with React Google Maps
- **Icons**: Lucide React icon library
- **Notifications**: React Hot Toast
- **Date Handling**: date-fns library

#### **Backend (Node.js Server)**
- **Runtime**: Node.js with Express.js framework
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT (JSON Web Tokens)
- **Real-time**: Socket.io for live updates
- **File Upload**: Multer for document handling
- **Security**: bcrypt for password hashing
- **Email/OTP**: Custom service integration

#### **Database Models**
- **User**: Passenger and driver profiles with authentication
- **Ride**: Ride postings with details, pricing, and status
- **Booking**: Ride reservations with payment tracking
- **Review**: Rating and feedback system
- **Chat**: Real-time messaging between users
- **Notification**: System notifications
- **Complaint**: Safety and issue reporting
- **SafetyRecord**: Incident tracking and verification

## 🎯 **Core Features**

### **1. User Authentication & Profiles**
- **Registration**: Separate flows for passengers and drivers
- **Login**: JWT-based secure authentication
- **Profile Management**: User details, documents, and preferences
- **Role-based Access**: Different permissions for passengers vs drivers

### **2. Ride Management System**

#### **For Drivers:**

- **Ride Tracking**: Monitor booking status and passenger details
- **Earnings Dashboard**: Track income and ride history

#### **For Passengers:**
- **Find Rides**: Search and filter available rides by location/route
- **Book Rides**: Reserve seats with instant confirmation
- **Ride Tracking**: Real-time status updates and OTP verification
- **Payment Processing**: Secure payment integration

### **3. Real-time Features**
- **Live Updates**: Socket.io powered real-time notifications
- **Ride Status**: Automatic updates for booking confirmations
- **OTP System**: Secure ride verification with time-based codes
- **Chat System**: In-app messaging between passengers and drivers

### **4. Safety & Security**
- **OTP Verification**: Mandatory OTP for ride start
- **Complaint System**: Report issues and safety concerns
- **Safety Records**: Track and verify ride safety
- **Emergency Features**: Quick access to emergency contacts

### **5. Dashboard Analytics**

#### **Passenger Dashboard:**

- **Recent Rides**: Card-based display of last 6 rides
- **Spending Summary**: Financial overview with cost analysis

#### **Driver Dashboard:**
- **Ride Management**: Active, upcoming, and completed rides
- **Earnings Tracking**: Revenue analytics and trends
- **Rating System**: Driver ratings and feedback

### **6. Maps & Location Services**
- **Google Maps Integration**: Interactive maps for ride visualization

### **7. Payment & Financial Features**
- **Secure Payments**: Integrated payment gateway
- **Fare Calculation**: Dynamic pricing based on distance and demand
- **Transaction History**: Complete payment records

## 📊 **Database Schema**

### **User Model**
```javascript
{
  name: String,
  email: String,
  password: String (hashed),
  phone: String,
  role: ['passenger', 'driver'],
  avatar: String,
  documents: [String], // File paths
  rating: Number,
  isVerified: Boolean,
  createdAt: Date
}
```

### **Ride Model**
```javascript
{
  driver: ObjectId (User),
  from: String,
  to: String,
  dateTime: Date,
  pricePerSeat: Number,
  availableSeats: Number,
  totalSeats: Number,
  status: ['active', 'completed', 'cancelled'],
  vehicle: {
    type: String,
    number: String,
    model: String
  },
  totalFare: Number, // For completed rides
  ratings: [{
    user: ObjectId,
    rating: Number,
    review: String
  }]
}
```

### **Booking Model**
```javascript
{
  user: ObjectId (User),
  ride: ObjectId (Ride),
  seatsBooked: Number,
  status: ['pending', 'confirmed', 'active', 'completed', 'cancelled'],
  totalAmount: Number,
  paymentStatus: ['pending', 'completed', 'refunded']
}
```

## 🔄 **API Endpoints**

### **Authentication**
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `GET /api/auth/profile` - Get user profile

### **Rides**
- `GET /api/rides` - Get all rides
- `POST /api/rides` - Create new ride
- `GET /api/rides/:id` - Get ride details
- `PUT /api/rides/:id` - Update ride

### **Bookings**
- `GET /api/bookings/my` - Get user's bookings
- `POST /api/bookings` - Create booking
- `PUT /api/bookings/:id/cancel` - Cancel booking

### **Reviews**
- `POST /api/reviews` - Submit review
- `GET /api/reviews/:rideId` - Get ride reviews
