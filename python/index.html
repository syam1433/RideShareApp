Introduction to Python

Python is a high-level, interpreted programming language that is easy to learn and widely used for web development, data science, automation, and AI.

print("Hello, Python!")

Python Keywords

Keywords are reserved words in Python that have predefined meanings and cannot be used as variable names.

if, else, for, while, break, continue, True, False

Identifiers

Identifiers are names used to identify variables, functions, or objects. They must start with a letter or underscore and cannot contain spaces.

student_name = "Ravi" totalMarks = 90

Variables

Variables are used to store data values in memory. Python does not require explicit declaration of variables.

x = 10 name = "Syam"

Comments

Comments are used to explain code and improve readability. Python supports single-line comments.

# This is a comment print("Python")

Data Types

Data types specify the type of data a variable holds such as integer, float, string, or boolean.

a = 10 # int b = 3.14 # float c = "Hello" # string d = True # boolean

Operators

Operators are symbols used to perform operations like addition, subtraction, comparison, etc.

a = 10 b = 5 print(a + b) print(a > b)

Input and Output

Input allows users to provide data, and output displays results on the screen.

name = input("Enter your name: ") print("Welcome", name)

Type Conversion

Type conversion is used to convert one data type into another.

x = "10" y = int(x) print(y + 5)

Debugging

Debugging is the process of identifying and fixing errors in a program.

Flow of Control

Flow of control determines the order in which statements are executed.

Selection Statements

age = 18 if age >= 18: print("Eligible to vote") else: print("Not eligible")

Loops (Repetition)

for i in range(5): print(i)

Break and Continue

for i in range(5): if i == 3: break print(i)

Nested Loops

for i in range(2): for j in range(2): print(i, j)

Strings

Strings are sequences of characters enclosed in quotes.

text = "Python" print(text[0])

String Handling Functions

msg = "hello" print(msg.upper()) print(len(msg))
